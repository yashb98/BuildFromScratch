    Step-by-step forward pass

    From token IDs to logits, with the exact tensor shape at every hop.

    1. step 1
      Token IDs → embeddings
      (B, T) → (B, T, 576)

      embed_tokens is an nn.Embedding(49152, 576) lookup. The same matrix is later transposed into lm_head.

    2. step 2
      Build RoPE cos/sin
      (T, 64) · (T, 64)

      Precomputed at model init for max_position_embeddings = 8192; sliced to length T per call. theta = 100,000.

    3. step 3
      Per layer — pre-norm
      (B, T, 576) → (B, T, 576)

      RMSNorm in fp32, then cast back. Pre-norm means the norm sits inside the residual branch, never on the residual itself.

    4. step 4
      Project to Q, K, V
      Q (B, 9, T, 64), K/V (B, 3, T, 64)

      Asymmetric: 9 query heads vs 3 KV heads — the GQA compression. No biases.

    5. step 5
      Apply RoPE to Q, K
      same shapes

      q*cos + rotate_half(q)*sin — encodes position by rotating halves of the head dim, not by adding a positional vector.

    6. step 6
      Repeat KV → 9 heads
      (B, 3, T, 64) → (B, 9, T, 64)

      repeat_interleave(3, dim=1) so SDPA can pair every Q head with a K/V head.

    7. step 7
      Causal SDPA
      (B, 9, T, 64)

      F.scaled_dot_product_attention(..., is_causal=True) — uses Flash Attention on supported GPUs.

    8. step 8
      Output proj + residual
      (B, T, 576)

      o_proj mixes heads back into hidden_size; result added to the residual stream.

    9. step 9
      Post-attn norm + SwiGLU MLP
      (B, T, 576) ↔ (B, T, 1536)

      down(silu(gate(x)) * up(x)). Two parallel up-projections fused via SiLU gating.

    10. step 10
      Repeat ×30, final norm
      (B, T, 576)

      After 30 blocks, one final RMSNorm before projecting to logits.

    11. step 11
      lm_head → vocab logits
      (B, T, 576) → (B, T, 49152)

      Tied with embed_tokens.weight — same tensor, no extra parameters.

    12. step 12
      Cross-entropy (training only)
      scalar

      Shift labels by 1; predict token t+1 from positions ≤ t. ignore_index=-100 for padding.

    RMSNorm

    lines 59–70 · nn.Module

    Root-Mean-Square LayerNorm (Zhang & Sennrich, 2019). Unlike LayerNorm it has no mean-subtraction and no bias — just rescale by the inverse RMS, then multiply by a learned gain. Computed in fp32 for stability, then cast back to the input dtype. 

    class RMSNorm(nn.Module):
    def __init__(self, hidden_size: int, eps: float):
        super().__init__()
        self.weight = nn.Parameter(torch.ones(hidden_size))
        self.eps = eps

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        dtype = x.dtype
        x = x.to(torch.float32)
        var = x.pow(2).mean(-1, keepdim=True)
        x = x * torch.rsqrt(var + self.eps)
        return (self.weight * x).to(dtype)
    • L62 Learned gain initialized to ones; one parameter per channel.
    • L66–67 Capture incoming dtype, promote to fp32 for the math.
    • L68 Mean of squares over the last dim: this is the RMS² per token.
    • L69 rsqrt avoids a divide; ε prevents divide-by-zero on degenerate vectors.
    • L70 Apply per-channel gain and cast back to bf16/fp16/fp32 — preserves caller dtype.

    Rotary Position Embeddings

    lines 84–106 · three helper functions

    RoPE encodes absolute position by rotating 2D pairs inside each attention head, so dot products between Q and K naturally encode relative position. SmolLM2 uses the "non-interleaved" layout (split last dim in half, rotate halves), matching HuggingFace. 

    def _build_rope_cache(seq_len, head_dim, theta, device, dtype):
    inv_freq = 1.0 / (theta ** (torch.arange(0, head_dim, 2, ...) / head_dim))
    t = torch.arange(seq_len, device=device, dtype=torch.float32)
    freqs = torch.outer(t, inv_freq)
    emb = torch.cat([freqs, freqs], dim=-1)
    return emb.cos().to(dtype), emb.sin().to(dtype)

def _rotate_half(x):
    x1, x2 = x.chunk(2, dim=-1)
    return torch.cat([-x2, x1], dim=-1)

def _apply_rope(q, k, cos, sin):
    cos = cos.unsqueeze(0).unsqueeze(0)
    sin = sin.unsqueeze(0).unsqueeze(0)
    q_out = (q * cos) + (_rotate_half(q) * sin)
    k_out = (k * cos) + (_rotate_half(k) * sin)
    return q_out, k_out
    • L86 inv_freq = 32 frequencies (head_dim/2). Lower index = faster rotation = shorter wavelength.
    • L87–88 Outer product of positions × frequencies → angle table of shape (seq_len, 32).
    • L89 Duplicate (concat with itself) so the cos/sin lines up with the half-split rotation in _rotate_half.
    • L95–96 "Rotate-half": pair channel i with channel i+32; this is the HF convention.
    • L102–103 Add batch + head dims via unsqueeze for broadcast over (B, H, T, D).
    • L104–105 The rotation: x' = x·cos + rotate_half(x)·sin. Note only Q and K are rotated, not V.
    Why this matters: using the wrong RoPE convention (interleaved vs split-half) is the most common cause of "weights load fine but generations are gibberish". The verify.py parity test exists primarily to catch exactly this class of bug.

    Attention — Grouped-Query, Causal, RoPE'd

    lines 116–163 · nn.Module

    The compute-heaviest module. Asymmetric Q vs KV projections (9 vs 3 heads), RoPE applied to Q and K only, KV repeated to match Q, then dispatched to PyTorch's fused scaled_dot_product_attention with a causal mask. 

    class Attention(nn.Module):
    def __init__(self, cfg):
        self.n_heads     = cfg.num_attention_heads     # 9
        self.n_kv_heads  = cfg.num_key_value_heads     # 3
        self.head_dim    = cfg.head_dim                # 64
        self.n_rep       = self.n_heads // self.n_kv_heads  # 3

        self.q_proj = nn.Linear(576, 9*64, bias=False)
        self.k_proj = nn.Linear(576, 3*64, bias=False)
        self.v_proj = nn.Linear(576, 3*64, bias=False)
        self.o_proj = nn.Linear(9*64, 576, bias=False)

    def forward(self, x, cos, sin, attention_mask=None):
        B, T, _ = x.shape
        q = self.q_proj(x).view(B, T, 9, 64).transpose(1, 2)
        k = self.k_proj(x).view(B, T, 3, 64).transpose(1, 2)
        v = self.v_proj(x).view(B, T, 3, 64).transpose(1, 2)

        q, k = _apply_rope(q, k, cos, sin)

        if self.n_rep > 1:
            k = k.repeat_interleave(self.n_rep, dim=1)
            v = v.repeat_interleave(self.n_rep, dim=1)

        out = F.scaled_dot_product_attention(
            q, k, v,
            attn_mask=attention_mask,
            dropout_p=0.0,
            is_causal=(attention_mask is None),
        )
        out = out.transpose(1, 2).contiguous().view(B, T, 9*64)
        return self.o_proj(out)
    • L120–123 Cache shape constants once for readability.
    • L130–133 Four nn.Linear projections, all bias-free per attention_bias=false.
    • L139–141 Reshape to (B, H, T, D) via view + transpose so the head dim is contiguous for SDPA.
    • L144 Rotate Q and K only — V doesn't carry positional info.
    • L149–151 Materialise the GQA repeat: each KV head broadcast to 3 Q heads. Modern PyTorch can do this implicitly with enable_gqa=True; explicit repeat keeps it version-agnostic.
    • L156–161 Single fused kernel — Flash Attention picks the path on supported GPUs. is_causal=True only when no explicit mask is provided.
    • L162–163 Reverse the head transpose, flatten heads, project back to hidden_size.

    SwiGLU MLP

    lines 172–180 · nn.Module

    Shazeer-2020 SwiGLU: two parallel up-projections (gate and up), one element-wise SiLU gate, then a single down-projection. No biases. Mathematically: down( silu(gate(x)) ⊙ up(x) ). 

    class MLP(nn.Module):
    def __init__(self, cfg):
        self.gate_proj = nn.Linear(576, 1536, bias=False)
        self.up_proj   = nn.Linear(576, 1536, bias=False)
        self.down_proj = nn.Linear(1536, 576, bias=False)

    def forward(self, x):
        return self.down_proj(F.silu(self.gate_proj(x)) * self.up_proj(x))
    • L175–176 Two up-projections — that's the "GLU" part. They share input but have independent weights.
    • L177 Down-projection back to residual width.
    • L180 silu(g) * u = the gated activation. SiLU = x · σ(x), smooth and self-gating.
    • params ≈ 2.65M / layer (3 × 576 × 1536), summed over 30 layers ≈ 79.7M — by far the biggest chunk of the model.

    Block — pre-norm transformer layer

    lines 188–199

    Standard pre-norm Llama block: norm → attn → residual → norm → MLP → residual. Module names (input_layernorm, self_attn, post_attention_layernorm, mlp) match HF exactly so safetensors keys align without remapping. 

    class Block(nn.Module):
    def __init__(self, cfg):
        self.input_layernorm           = RMSNorm(576, eps)
        self.self_attn                 = Attention(cfg)
        self.post_attention_layernorm  = RMSNorm(576, eps)
        self.mlp                       = MLP(cfg)

    def forward(self, x, cos, sin, attention_mask=None):
        x = x + self.self_attn(self.input_layernorm(x), cos, sin, attention_mask)
        x = x + self.mlp(self.post_attention_layernorm(x))
        return x
    • L191–194 Two norms + one attn + one MLP per block — total 120 norms in the full 30-layer stack.
    • L197 Pre-norm pattern: norm sits inside the residual branch, so the residual is never normalized. This is what makes very deep stacks trainable.
    • L198 Same again with the MLP. Every block is a "compute, scale, add" unit.

    SmolLM2Model — embedding + stack + final norm

    lines 212–235

    Mirrors LlamaModel: one token embedding, a ModuleList of 30 blocks, one final RMSNorm. RoPE tables are precomputed once and registered as persistent=False buffers so they don't pollute state_dict. 

    class SmolLM2Model(nn.Module):
    def __init__(self, cfg):
        self.embed_tokens = nn.Embedding(49152, 576)
        self.layers = nn.ModuleList([Block(cfg) for _ in range(30)])
        self.norm = RMSNorm(576, cfg.rms_norm_eps)

        cos, sin = _build_rope_cache(8192, 64, 100_000.0, 'cpu', float32)
        self.register_buffer('rope_cos', cos, persistent=False)
        self.register_buffer('rope_sin', sin, persistent=False)

    def forward(self, input_ids, attention_mask=None):
        T = input_ids.shape[1]
        x = self.embed_tokens(input_ids)
        cos = self.rope_cos[:T].to(x.dtype)
        sin = self.rope_sin[:T].to(x.dtype)
        for layer in self.layers:
            x = layer(x, cos, sin, attention_mask)
        return self.norm(x)
    • L216 The embedding table — shared with the LM head via weight tying.
    • L217 30 identical blocks in a list comprehension — each gets its own parameters.
    • L223 Build cos/sin once at max_position_embeddings = 8192; sliced per call.
    • L225–226 persistent=False keeps these out of state_dict, so HF's safetensors (which ship no RoPE tables) load cleanly.
    • L231–232 Cast cos/sin to the activation dtype each call — supports bf16 training without losing the fp32 cache.
    • L233–235 The 30 layers run sequentially; final norm applied once after the last residual.

    SmolLM2ForCausalLM — head, init, loss, generate

    lines 238–301

    Wraps the model with the LM head, the cross-entropy loss, the weight-init recipe, and a minimal greedy/top-k generator. Mirrors LlamaForCausalLM's public surface so loaders, generators, and HF tooling can use it as a drop-in. 

    class SmolLM2ForCausalLM(nn.Module):
    def __init__(self, cfg):
        self.model = SmolLM2Model(cfg)
        self.lm_head = nn.Linear(576, 49152, bias=False)
        if cfg.tie_word_embeddings:
            self.lm_head.weight = self.model.embed_tokens.weight
        self.apply(self._init_weights)

    def _init_weights(self, module):
        std = self.cfg.initializer_range
        if isinstance(module, nn.Linear):
            nn.init.normal_(module.weight, mean=0.0, std=std)
            if module.bias is not None:
                nn.init.zeros_(module.bias)
        elif isinstance(module, nn.Embedding):
            nn.init.normal_(module.weight, mean=0.0, std=std)

    def forward(self, input_ids, labels=None, attention_mask=None):
        hidden = self.model(input_ids, attention_mask)
        logits = self.lm_head(hidden)
        if labels is not None:
            shift_logits = logits[..., :-1, :].contiguous()
            shift_labels = labels[..., 1:].contiguous()
            loss = F.cross_entropy(
                shift_logits.view(-1, shift_logits.size(-1)),
                shift_labels.view(-1),
                ignore_index=-100,
            )
        return {"logits": logits, "loss": loss}

    @torch.no_grad()
    def generate(self, input_ids, max_new_tokens=64, temperature=0.8, top_k=50):
        for _ in range(max_new_tokens):
            ctx = input_ids[:, -self.cfg.max_position_embeddings:]
            logits = self.forward(ctx)["logits"][:, -1, :]
            if temperature <= 0:
                next_token = logits.argmax(dim=-1, keepdim=True)
            else:
                logits = logits / temperature
                if top_k is not None:
                    v, _ = torch.topk(logits, top_k)
                    logits[logits < v[:, [-1]]] = -float('inf')
                probs = F.softmax(logits, dim=-1)
                next_token = torch.multinomial(probs, num_samples=1)
            input_ids = torch.cat([input_ids, next_token], dim=1)
        return input_ids
    • L242–243 Compose the backbone + LM head. lm_head projects 576 → 49,152.
    • L244–247 Weight tying — assigning the parameter aliases the storage; it's not a copy.
    • L248 Recursive init, walks every submodule.
    • L255–260 Linear and Embedding both init to N(0, 1/√576); biases (if any) zero. RMSNorm gain stays at 1 (set in its own __init__).
    • L266–267 Forward path: backbone → LM head → vocab logits.
    • L272–278 Causal shift: predict t+1 from positions ≤ t; flatten over (batch, time) for CE.
    • L281–282 Inference-only generator; no KV cache (recomputes prefix each step) — fine for the educational starter.
    • L289 Truncate context to model's max position to avoid out-of-range RoPE.
    • L294–299 Top-k sampling: divide by T, mask all but top k, softmax, multinomial.

    make_wsd_scheduler

    lines 47–59 · Warmup-Stable-Decay

    Three-phase LR schedule used by SmolLM2: linear warmup, long stable plateau at peak LR, then linear decay-to-zero across the last decay_frac of training. The decay window is what produces the final low-loss "annealing" phase. 

    def make_wsd_scheduler(optimizer, warmup_steps, total_steps, decay_frac=0.2):
    decay_start = int(total_steps * (1.0 - decay_frac))

    def lr_lambda(step):
        if step < warmup_steps:
            return step / max(1, warmup_steps)
        if step < decay_start:
            return 1.0
        decay_progress = (step - decay_start) / max(1, total_steps - decay_start)
        return max(0.0, 1.0 - decay_progress)

    return LambdaLR(optimizer, lr_lambda)
    • L48 First 80% = warmup + stable; final 20% = decay.
    • L51–52 Linear warmup ramp from 0 → 1.
    • L53–54 Hold at peak across the stable window.
    • L56–57 Linear decay to 0 across the last decay_frac fraction.
    • L59 Wrap with LambdaLR — multiplier applied to the optimizer's base LR (3e-3).

    PackedTextDataset

    lines 67–80 · torch.utils.data.Dataset

    Tokens are pre-tokenized into one long 1-D tensor and re-served as fixed-length windows. Each sample yields aligned (input_ids, labels) with labels shifted by one — a standard "next-token-prediction" packing. 

    class PackedTextDataset(torch.utils.data.Dataset):
    def __init__(self, token_ids, seq_len):
        self.tokens = token_ids
        self.seq_len = seq_len
        self.n_windows = (len(token_ids) - 1) // seq_len

    def __len__(self):
        return self.n_windows

    def __getitem__(self, idx):
        start = idx * self.seq_len
        chunk = self.tokens[start:start + self.seq_len + 1]
        return chunk[:-1], chunk[1:]
    • L71 (N - 1) // L: leave one extra token so the last window has a label.
    • L79 Slice L+1 tokens — input and label share L-1 tokens of overlap, shifted by one.
    • L80 Returns (inputs, labels) already aligned — no further shift in the train loop.
    • caveat No cross-document attention masking — fine for a tiny demo, replace with a real packer for serious runs.

    build_dataset

    lines 83–98

    Streams wikitext-103-raw, tokenizes everything once with the official SmolLM2 BPE, separates documents with EOS, and hands the resulting 1-D tensor to PackedTextDataset. 

    def build_dataset(tokenizer, seq_len):
    from datasets import load_dataset
    ds = load_dataset("Salesforce/wikitext", "wikitext-103-raw-v1", split="train")
    eos = tokenizer.eos_token_id
    all_ids = []
    for ex in ds:
        text = ex["text"]
        if not text.strip():
            continue
        all_ids.extend(tokenizer.encode(text, add_special_tokens=False))
        all_ids.append(eos)
    tokens = torch.tensor(all_ids, dtype=torch.long)
    print(f"Packed {len(tokens):,} tokens into windows of {seq_len}.")
    return PackedTextDataset(tokens, seq_len)

    model = SmolLM2ForCausalLM(cfg).to(device=device, dtype=dtype)
    model.train()

    decay, no_decay = [], []
    for n, p in model.named_parameters():
        if p.requires_grad:
            (no_decay if p.dim() < 2 else decay).append(p)
    optim = AdamW(
        [{"params": decay,    "weight_decay": args.weight_decay},
         {"params": no_decay, "weight_decay": 0.0}],
        lr=args.lr, betas=(0.9, 0.95), eps=1e-8,
    )
    sched = make_wsd_scheduler(optim, args.warmup_steps, args.steps, decay_frac=0.2)

    while step < args.steps:
        for inputs, labels in loader:
            logits = model(input_ids=inputs)["logits"]
            loss = F.cross_entropy(logits.reshape(-1, V), labels.reshape(-1))
            (loss / args.grad_accum).backward()
            accum += 1

            if accum == args.grad_accum:
                torch.nn.utils.clip_grad_norm_(model.parameters(), args.grad_clip)
                optim.step()
                sched.step()
                optim.zero_grad(set_to_none=True)
                accum = 0
                step += 1

    torch.save({"model": model.state_dict(), ...}, "checkpoint.pt")
